# EitaFeed — primeira versão

Portal responsivo de entretenimento em português, feito com HTML, CSS e JavaScript puro. Não exige frameworks, banco de dados ou build.

## Arquivos
- `index.html`: conteúdo e estrutura do portal.
- `styles.css`: identidade visual e layout responsivo.
- `script.js`: quiz interativo, resultados e compartilhamento.

## Testar localmente
Abra `index.html` no navegador. Para desenvolvimento, também pode usar a extensão Live Server do VS Code.

## Publicar gratuitamente com GitHub Pages
1. Crie ou entre em uma conta em https://github.com/
2. Crie um repositório público, por exemplo `eitafeed`.
3. Envie os três arquivos (`index.html`, `styles.css`, `script.js`) e este README para a raiz do repositório.
4. No repositório, abra **Settings → Pages**.
5. Em **Build and deployment**, escolha **Deploy from a branch**.
6. Selecione a branch `main` e a pasta `/ (root)` e clique em **Save**.
7. Aguarde a publicação. O GitHub mostrará o endereço do site na mesma tela, normalmente no formato `https://SEU-USUARIO.github.io/eitafeed/`.

A hospedagem do GitHub Pages está disponível gratuitamente para repositórios públicos em contas GitHub Free. Os menus podem variar um pouco com o idioma da conta.

## Antes de divulgar
- O nome EitaFeed é provisório: faça uma pesquisa de marca e domínio antes de investir na marca.
- As chamadas de matérias na página inicial são exemplos de pauta, não notícias factuais publicadas.
- A newsletter é apenas visual e não coleta nem envia e-mails.
- O site não tem backend, login, analytics ou sistema editorial; tudo é estático.
- Use textos, fotos, ilustrações e memes próprios ou com licença adequada. Não copie artigos, imagens ou identidade visual de outros portais.
- Inclua política de privacidade e aviso de cookies se futuramente adicionar analytics, anúncios ou coleta de dados.
